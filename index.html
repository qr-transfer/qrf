Why it works offline
Embedded compression — zstd (WebAssembly) + native gzip, inlined; nothing is fetched.
Fountain codes — recover the file even if some frames are missed.
Integrity verified — the original checksum is checked before download.
Self-contained — single HTML files; open straight from disk if you prefer.
